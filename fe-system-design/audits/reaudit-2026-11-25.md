## Fixed today

Security and correctness:

1–5. **Five security hardening fixes** (request routing, the backend proxy, uploads, outbound links, data kept on the device). This repository is public, so the details are in the local security notes, not here.
6. **Dashboard links with bad dates** (`?period=custom:x:y`, `?compare=bogus`) could make every later save throw outside its error handling. Dates are validated in the link, the reducer and the save, and the save runs inside a promise.
7. **Dashboard stores never reset**: "No access" and another warehouse's sync state came back after leaving and returning. Both stores reset on unmount.
8. **Reconnect return address leaked into sign-in popups** (introduced 2026-11-25 in 88102f98): the Connectors page wrote it on load and a popup copies session storage. It's now written only just before a full-page sign-in.
9. **A failed agents list showed "Create your first agent"**. Now it says it couldn't load, with Try again; one bad row is dropped instead of failing the whole list; the usual retry policy applies.
10. **Stale legacy avatar/tag overrides** from the deleted agent editor hid agents' real avatars and tags on /agents. Removed.
11. **Editing a schedule with a trigger the form can't express** (every few minutes, an app event, once) opened on "Daily 9:00" and saving asked Task to change it. The trigger is now shown as it is and left alone unless the person chooses to replace it.
12. **Search listed project and agent chats twice** (GET /chats returns them too); the two rows shared a DOM id. Each chat is now listed once, in its most specific group. The hidden Pins tab and placeholder text are gone while Pins is off.

Performance, accessibility and housekeeping:

13. **Mixpanel identity effect** re-ran on every `["me"]` refetch and token refresh (after every chat turn), sending an identify and a profile update each time. It now runs only when the user, plan or org changes.
14. **Reduced motion**: `MotionConfig reducedMotion="user"` app-wide. framer-motion animations ignored the OS setting before.
15. **Route files**: `error.tsx` for `(onboarding)` and `(standalone)` (plan pickers, checkout); a branded root `not-found.tsx`.
16. **Legacy settings stubs** (`/settings/billing`, `/settings/plans`, `/settings/plans/confirmation`) are server redirects now. Two of them sat under the admin gate, so members following an old link saw "only admins".
17. **Theme drift**: the dashboard's dark tokens moved from `semantic.css` into the generator's project overrides; `theme.css` regenerated.
18. **Dead code removed**: `lib/agui-stream.ts` (+test), `PresetModelSelector`, `ModelFeaturedCard`, `AgentEditor/FineTuneModal`, `AgentEditor/TryItBox`, `ConnectorRequestRow`, `ConnectorStatusBadge`, `ConnectorPausedBadge`, `listModels`/`testModels` and their types and endpoint. About 1,300 lines. `agent_tested` joins the not-yet-wired analytics list (its only call was in the never-mounted TryItBox).
19. Tests: 12 ChatInput snapshots updated (reviewed: token swaps and the hover-revealed model caret), billing copy test aligned.

Live checks (dev server, admin test account; warehouse stood in where noted): 20 audit checks, 23 dashboard fix checks, 21 dashboard round-2 checks and 7 empty-state checks, all passing.
